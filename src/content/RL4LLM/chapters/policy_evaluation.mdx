## Policy Evaluation

在 [Bellman Equation Theorem](#bellman-equation-theorem) 一节中，我们看到 $V^\pi$ 是 Bellman operator $\mathcal T^\pi$ 的唯一不动点。
Bellman optimality equation 直接寻找最优价值，而本章先解决一个更基础的 **evaluation** 问题：

<Note variant="info">

给定一个策略 $\pi$，如何高效求解策略 $\pi$ 对应的 value function $V^\pi$?

</Note>

我们将先从完整 MDP 模型的精确解法，逐步过渡到只依赖 rollout 的 MC/TD 方法和现代 RL 使用的函数逼近方法。
本章始终固定 $\pi$：无论更新 Q-table 还是 neural network，改变的都只是对这个策略的价值估计，生成动作的规则不变。
我们依次回答三个问题：

1. 已知完整环境模型，如何精确计算 $V^\pi$？
2. 只能采样 rollout 时，如何用 MC/TD 估计 $V^\pi$？
3. 状态太多时，如何用函数逼近在不同 prefix 之间共享信息？

如何利用这些估计改变策略，将留到下一章 [Value Based Methods](#value-based-methods)。

### Running Example: Evaluating a Frozen ToyLLM

沿用 [ToyLLM](#running-example-toyllm)，取普通词表 $\{A,B\}$、最大生成长度 $T=2$、target response $y^*=(B,A)$，并令 $\gamma=1$。
动作空间还包含 `<eos>`；提前结束或生成其他 response 均获得零奖励。
假设当前固定策略满足

$$
\pi(A\mid x)=0.6,\quad \pi(B\mid x)=0.3,\quad
\pi(\langle\mathrm{eos}\rangle\mid x)=0.1,\qquad
\pi(A\mid x,B)=0.5.
$$

在 prefix $B$ 之后，其余动作共享剩下的 $0.5$ 概率，具体分配不影响下面的计算。
由于只有 response $BA$ 成功，

$$
V^\pi(x,B)=0.5,\qquad
Q^\pi(x,B)=0.5,\qquad
Q^\pi(x,A)=Q^\pi(x,\langle\mathrm{eos}\rangle)=0,
$$

$$
V^\pi(x)=0.3\times0.5=0.15.
$$

这里 $V^\pi(x,B)$ 表示到达 prefix $B$ 后的价值，而 $Q^\pi(x,B)$ 表示在初始状态 $x$ 选择动作 $B$ 的价值；二者在这个零中间奖励、$\gamma=1$ 的例子中相等。
无论使用哪种 evaluation 方法，我们的目标都是恢复这些数值。
**即使已经知道动作 $B$ 比 $A$ 更好，本章也不会修改 $\pi(B\mid x)=0.3$。**

<Note variant="info">

一般 finite-horizon MDP 的价值还依赖剩余时间，可以把时间并入 state。
ToyLLM 的 prefix 长度已经包含这一信息，终止状态的 value 统一设为零。
以下 contraction 论证使用 $0<\gamma<1$；ToyLLM 在 $\gamma=1$ 时仍可按 prefix 长度做有限步 backward induction，不能直接套用严格 contraction 的论证。

</Note>

### Tabular Learning

这一节我们介绍针对离散小空间场景下的求解和优化方案。

#### Tabular Learning with Matrix Solve

对于有限状态空间，固定策略的 [Bellman Equation](#bellman_equation_value) 可以写成线性方程组。这里计算的是 $V^\pi$，不是 value iteration 所寻找的 $V^*$：

$$
V_{\pi} = R_{\pi} + \gamma P_{\pi} V_{\pi}
$$

其中

$$
\begin{aligned}
   V_\pi &= [V_{\pi}(s_1),\dots, V_{\pi}(s_S)]^T\in\mathbb{R}^S\\
   R_\pi &=[R_{\pi}(s_1),\dots, R_{\pi}(s_S)]^T\in\mathbb{R}^S\\
   P_\pi &=[P_\pi(s_j\mid s_i)]\in\mathbb{R}^{S\times S}
\end{aligned}
$$

其中 $R_\pi(s)=\mathbb E[r\mid s,a\sim\pi]$，$P_\pi$ 对动作按固定策略求平均。
我们只编号非终止状态，因此转移到 terminal 的概率质量不写入 $P_\pi$，其行和可以小于 1。
于是

$$
(\mathbf{I}_S - \gamma P_{\pi})V_{\pi}  = R_{\pi}
$$

实现时使用线性求解器 `SOLVE`，不必显式计算逆矩阵。
下面的 `STEP(s,a)` 伪代码针对 ToyLLM 这样的确定性 reward/transition；随机环境需要枚举并加权所有可能的 $(r,s')$，单次 `STEP` 样本不能给出精确模型。
这里 $\mathcal S$ 在算法输入中指非终止状态集合。
精确算法如下所示

<Algorithm title="Value function Matrix Exact Solve">

**Input**: policy $\pi$, discount factor $\gamma$, state space $\mathcal{S}$ with size $S$

1. assign index $i(s)$ for $s\in\mathcal{S}, i=1,\dots,S$
2. $P=\mathbf{0}_{S\times S}$, $R=\mathbf{0}_{S}$
3. **For** each $s\in\mathcal{S}$
   1. $i\gets i(s)$
   2. **For** each $a\in\mathcal{A}$
      - $(s', r, \mathrm{done}) \gets \mathrm{STEP}(s, a)$
      - $R[i]\gets R[i]+\pi(a\mid s)\cdot r$
      - **If** NOT $\mathrm{done}$
        - $j\gets i(s')$
        - $P[i,j]\gets P[i,j]+\pi(a\mid s)$
4. $V\gets \mathrm{SOLVE}(I_S-\gamma P, R)$
5. return $V$

</Algorithm>

迭代算法则是给定随机初始化的 $V_0$, 我们通过迭代计算得到序列 $\{V_k\}$, 其中 $V_{k+1}=R_{\pi} + \gamma P_{\pi}V_k$, 我们可以证明这个序列收敛到 $V_{\pi}$.

<Algorithm title="Value function Matrix Iterative Solve">

**Input**: policy $\pi$, discount factor $\gamma$, convergence threshold $\theta$, state space $\mathcal{S}$

1. $V(s)=0, s\in\mathcal{S}$, $\Delta=\infty$.
2. **While** $\Delta > \theta$:
   1. $\Delta\gets0$
   2. **For** each $s\in\mathcal{S}$
      1. $v\gets0$
      2. **For** each $a\in\mathcal{A}$
         - $(s', r, \mathrm{done}) \gets \mathrm{STEP}(s, a)$
         - **If** $\mathrm{done}$
           - $v \gets v + \pi(a|s) \cdot r$
         - **Else**
           - $v \gets v + \pi(a|s) \cdot (r + \gamma \cdot V(s'))$
      3. $\Delta ← max(\Delta, |v − V(s)|)$
      4. $V(s) \gets v$
3. return $V$

</Algorithm>

对 ToyLLM 的有限生成树，还可以按 prefix 长度倒序计算，避免稠密矩阵求解；但这仍需要访问所求解的状态。
下面是两种已有实现的求解时间变化曲线

<Image
  src={Matrix_Solve}
  alt="Comparison of matrix solve and iterative solve"
/>

可以看到，由于稠密线性方程组的直接求解通常需要 $\mathcal{O}(S^3)$ 时间和 $\mathcal{O}(S^2)$ 空间，随着状态数 $S$ 的增加，其所需时间急剧上升。
而迭代解法虽然比矩阵直接求解效率更高，但是仍然需要枚举全部状态，当状态空间增大之后，迭代解法的时间也无法接受。
因此，我们需要计算更加高效的算法。

#### Tabular Learning with MC

由 $V^{\pi}$ 定义，我们有：

$$
V^{\pi}(s_0) = \mathbb{E}^{\pi}\left[R(\tau) \mid s_0\right]
$$

由于 return 是一个随机变量，我们可以利用 Monte Carlo (MC) 方法得到一个 [Unbiased Estimator](https://maosong.website/blog/math/#probability)，即从 $s_0$ 出发，独立随机采样 (i.i.d.) $M$ 条轨迹：

$$
\{\tau^{(i)} = (s_0, a_0^{(i)}, r_0^{(i)}, \dots, a_{T^{(i)}-1}^{(i)}, r_{T^{(i)}-1}^{(i)}, s_{T^{(i)}}^{(i)})\}, \quad i = 1, \dots, M
$$

然后我们使用样本平均 (sample mean) 来近似期望：

$$
V^{\pi}(s_0) = \mathbb{E}^{\pi}[R(\tau) \mid s_0] \approx \frac{1}{M} \sum_{i=1}^{M} R(\tau^{(i)})
$$

对应的算法如下所示

<Algorithm title="Tabular Learning with MC">

**Input**: policy $\pi$, discount factor $\gamma$, episodes $M$, state space $\mathcal{S}$, initial state distribution $p_0$

1. $V(s)=0, \mathrm{ReturnSum}(s)=0, \mathrm{ReturnCount}(s)=0, s\in\mathcal{S}$
2. **For** $\mathrm{episode}=1,2,\dots,M$:
   1. $s\sim p_0$, $\mathrm{done}=\mathrm{false}$, $\tau=[]$
   2. **While** not $\mathrm{done}$:
      - $a\sim\pi(\cdot\mid s)$
      - $(s', r, \mathrm{done}) \gets \mathrm{STEP}(s, a)$
      - $\tau.\mathrm{append}((s,r))$
      - $s\gets s'$
   3. $\mathrm{Returns}=[]$, $G\gets0$
   4. **For** $(s,r)$ in $\mathrm{reversed}(\tau)$
      - $G\gets r + \gamma G$
      - $\mathrm{Returns}.\mathrm{prepend}((s,G))$
   5. $\mathrm{Visited}=\emptyset$
   6. **For** $(s,G)$ in $\mathrm{Returns}$
      - **If** $s\not\in \mathrm{Visited}$
        - $\mathrm{Visited}.\mathrm{add}(s)$
        - $\mathrm{ReturnSum}(s) \gets \mathrm{ReturnSum}(s) +G$
        - $\mathrm{ReturnCount}(s) \gets \mathrm{ReturnCount}(s)+ 1$
        - $V(s)\gets \mathrm{ReturnSum}(s) / \mathrm{ReturnCount}(s)$
3. return $V$

</Algorithm>

<Note variant="remark" emoji="💡">

上面的伪代码使用了 First-Visit MC：在一个 episode 内，同一个状态可能出现多次，但我们只用它第一次出现位置之后的 return 来更新该状态。

</Note>

#### Tabular Learning with TD

MC 的优点是 [estimator](https://maosong.website/blog/math/#estimator) 是一个 unbiased estimator, 其缺点在于我们必须完整采样完一条轨迹才能得到这个估计，对于 long-horizon task, MC 方法效率很低。

为了解决这个问题，我们可以使用 Temporal difference (TD) learning 方法。
Temporal difference (TD) learning 通过相邻两步的转换关系来近似 value function.
其核心思想在于

<Note variant="info">

通过新的信息和新的预测来更新旧的预测

</Note>

注意到：

$$
V^{\pi}(s_t) = \mathbb{E}^{\pi}[r_t + \gamma V^{\pi}(s_{t+1}) \mid S_t=s_t]
$$

我们首先定义 TD target 和 TD error 如下

<Definition term='TD target and TD error' variant='info'>

给定当前 estimator $V_t$，我们定义 one-step **TD target** 为

$$
\overline{V}_t =
\begin{cases}
r_t,&\text{if }s_{t+1}\text{ is terminal},\\
r_t+\gamma V_t(s_{t+1}),&\text{otherwise}.
\end{cases}
$$

定义 **TD error** 为

$$
\delta_t = \overline{V}_t - V_t(s_t).
$$

</Definition>

接下来，我们基于 TD error 更新 $V_t$：

$$
V_{t+1}(s) = \begin{cases}
   V_t(s_t) + \alpha_t(s_t)\delta_t,&\text{if }s=s_t,\\
   V_t(s),&\text{otherwise}.
\end{cases}
$$

其中 $\alpha_t(s_t) \in (0, 1)$ 是 learning rate.

TD learning 对应的算法如下所示

<Algorithm title="Tabular Learning with TD">

**Input**: policy $\pi$, discount factor $\gamma$, learning rate $\alpha$, episodes $M$, state space $\mathcal{S}$, initial state distribution $p_0$

1. $V(s)=0, s\in\mathcal{S}$
2. **For** $\mathrm{episode}=1,2,\dots,M$:
   1. $s\sim p_0$, $\mathrm{done}=\mathrm{false}$
   2. **While** not $\mathrm{done}$:
      - $a\sim\pi(\cdot\mid s)$
      - $(s', r, \mathrm{done}) \gets \mathrm{STEP}(s, a)$
      - **If** $\mathrm{done}$
        - $y\gets r$
      - **Else**
        - $y \gets r + \gamma \cdot V(s')$
      - $V(s)\gets V(s) + \alpha\cdot(y-V(s))$
      - $s\gets s'$
3. return $V$

</Algorithm>

一次 TD 更新可以写成

$$
V_{t+1}(s_t)=(1-\alpha_t)V_t(s_t)+\alpha_t\overline V_t.
$$

因此，当 $0<\alpha_t<1$ 时，新估计向本次 sampled target 移动。
但是 $\overline V_t$ 本身随采样和 $V_t$ 改变，**向当前 target 靠近不等于已经证明收敛**。
给定采样前的历史 $\mathcal F_t$（其中包含 $V_t$ 和 $s_t$），on-policy 采样满足

$$
\mathbb E[\delta_t\mid\mathcal F_t]
=(\mathcal T^\pi V_t)(s_t)-V_t(s_t).
$$

也就是说，TD error 的条件期望是当前估计的 Bellman residual。
当 $V_t=V^\pi$ 时，这个期望为零，但单次 TD error 仍可能非零；它不是已知的 $V^\pi-V_t$。

<Theorem title="Convergence of Tabular TD (discounted case)">

对有限 MDP、固定策略 $\pi$、有界奖励和 $0<\gamma<1$，若所有待估计的非终止状态均被无限次访问，并且每个状态按自身访问次数编号的步长满足

$$
\sum_{n=1}^{\infty}\alpha_n(s)=\infty,\qquad
\sum_{n=1}^{\infty}\alpha_n(s)^2<\infty,
$$

则标准 on-policy tabular TD(0) 的估计几乎必然收敛到 $V^\pi$。
未被访问的状态不享有这一保证；常数步长实验也不满足上述递减步长条件。

</Theorem>

<Sidenote>

关于 tabular TD 的随机逼近分析，可参考 [Mathematical Foundations of Reinforcement Learning](https://github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning) 中的 TD learning 章节。

</Sidenote>

回到 ToyLLM：若所有 value 初始化为零，一次成功的 $BA$ rollout 会让 MC 同时更新初始状态和 prefix $B$。
按时间顺序更新的 one-step TD 则先用尚为零的 $V(x,B)$ 更新初始状态，再从 terminal reward 更新 $V(x,B)$；之后再次访问时，奖励信息才继续向前传播。
这解释了为什么在这个小例子中，MC 可能比 TD 更快，而不意味着 MC 在所有任务中都更高效。

### Function Approximation

上面我们介绍了 MC 和 TD 两种 value function 估计方法，但是当动作空间和状态空间特别大时，tabular learning 仍然存在扩展性问题。
为了解决这个扩展性不足的问题，当状态空间 $\mathcal{S}$ 较大或连续时，我们可以使用函数逼近的方法来近似 $V^{\pi}$.

这里我们使用 $V_{\phi}:\mathcal{S}\to\mathbb{R}$ 近似 $V^{\pi}$，其中 $\phi$ 是参数。
令 $d^\pi$ 为固定策略在 rollout 中诱导的状态访问分布。将非终止状态的期望访问次数归一化，可写为

$$
d^\pi(s)=\frac{\mathbb E_{\tau\sim\pi}[\sum_{t=0}^{T(\tau)-1}\mathbf 1\{s_t=s\}]}{\mathbb E_{\tau\sim\pi}[T(\tau)]}.
$$

它对应按 transition 加权，而不是每条 episode 权重相同。
我们使用 mean squared value error:

<Sidenote>

See Chapter 7 of [Mathematical Foundations of Reinforcement Learning](https://github.com/MathFoundationRL/Book-Mathematical-Foundation-of-Reinforcement-Learning) for more details on $d^\pi$.

</Sidenote>

$$
\mathcal{L}(\phi) = \mathbb{E}_{s \sim d^\pi}\left[\frac{1}{2}\left(V_{\phi}(s) - V^{\pi}(s)\right)^2\right].
$$

$V^\pi(s)$ 满足 $V^\pi(s)=\mathbb E^\pi[G\mid S=s]$, 因此：

$$
\begin{aligned}
\nabla_{\phi} \mathcal{L}(\phi)
&= \mathbb{E}_{s \sim d^\pi}
\left[\left(V_{\phi}(s)-V^\pi(s)\right)\nabla_{\phi}V_{\phi}(s)\right]\\
&= \mathbb{E}_{s \sim d^\pi,\,G\sim\pi(\cdot\mid s)}
\left[\left(V_{\phi}(s)-G\right)\nabla_{\phi}V_{\phi}(s)\right].
\end{aligned}
$$

#### Function Approximation with MC

现在我们可以使用 MC 方法来估计梯度：

$$
\nabla_{\phi} \mathcal{L}(\phi) \approx g
:= \frac{1}{M}\sum_{i=1}^{M}
\left(V_{\phi}(s^{(i)})-G^{(i)}\right)\nabla_{\phi}V_{\phi}(s^{(i)}).
$$

结合 MC 和 SGD 的算法如下：

<Algorithm title="Value function approximation with MC">

**While** not converged:

1. 从固定策略的状态访问分布采样非终止状态 $s\sim d^\pi$。
2. 从这个状态开始，固定 $\pi$，采样一条新的 continuation，直到 terminal。
3. 计算该 continuation 的 discounted return $G$。
4. $g\gets(V_\phi(s)-G)\nabla_\phi V_\phi(s)$。
5. 使用 $g$ 做 gradient descent，更新 $\phi$。

</Algorithm>

上面将“选训练状态”和“从该状态采样 return”分开，以明确条件期望。
实际训练也可以像 tabular MC 一样复用完整 rollout 的每个 prefix，并把各自的 $G_t$ 当作监督信号。
批处理时应明确按 transition 还是按 episode 加权；变长 episode 下，二者一般对应不同的训练目标。

#### Function Approximation with TD

如果能够访问真实的 $V^\pi(s')$，我们可以将一步 TD target 当作监督信号：

$$
\mathcal{L}(\phi) = \mathbb{E}_{s \sim d^\pi}^\pi
\left[\frac{1}{2}\left(V_{\phi}(s)-\left(\textcolor{red}{r+\gamma V^{\pi}(s')}\right)\right)^2\right].
$$

对应的梯度为：

$$
\nabla_{\phi} \mathcal{L}(\phi)
=\mathbb{E}_{s \sim d^\pi}^{\pi}
\left[\left(V_{\phi}(s)-r-\gamma \textcolor{red}{V^{\pi}(s')}\right)
\nabla_{\phi}V_{\phi}(s)\right].
$$

这里梯度包含了一个未知量 $V^{\pi}(s')$.
为了解决这个问题，一个自然的想法是使用当前的 value function $V_{\phi}(s')$ 来进行代替：

$$
g:=\mathbb{E}_{s \sim d^\pi}^{\pi}
\left[\left(V_{\phi}(s)-r-\gamma V_{\phi}(s')\right)
\nabla_{\phi}V_{\phi}(s)\right].
$$

这里的 $g$ 只沿当前预测求导。若直接把 bootstrap target 写入普通平方损失，autograd 会产生不同的梯度。
下面先以一个非终止 transition 展示这个实现陷阱：

```python
pred = V_phi(s0)
target = r + gamma * V_phi(s1)
td_error = pred - target
loss = 0.5 * td_error ** 2
loss.backward()
```

可以看到，我们实际上求的梯度是：

$$
\begin{aligned}
&\nabla_{\phi}\left[\frac{1}{2}\left(V_{\phi}(s) - (r + \gamma V_{\phi}(s'))\right)^2\right] \\
&= (V_{\phi}(s) - (r + \gamma V_{\phi}(s')))
(\nabla_{\phi} V_{\phi}(s) - \gamma\nabla_{\phi} V_{\phi}(s'))\\
&\neq g
\end{aligned}
$$

为了解决这个问题，我们可以使用 **stop-gradient** 技巧来避免 $V_{\phi}(s')$ 参与反向传播，此时目标函数变为：

$$
\mathcal{L}(\phi)=\frac{1}{2}\left(V_{\phi}(s) - (r + \gamma \, \mathrm{sg}[V_{\phi}(s')])\right)^2
$$

其中 $\mathrm{sg}[\cdot]$ 是 stop-gradient operator, 满足：

$$
\mathrm{sg}[x]=x\quad\text{(forward)},\qquad
\frac{\partial\,\mathrm{sg}[x]}{\partial x}=0\quad\text{(autograd)}
$$

对应的梯度就是：

$$
\nabla_{\phi}\left[\frac{1}{2}\left(V_{\phi}(s) - (r + \gamma \, \mathrm{sg}[V_{\phi}(s')])\right)^2\right] = (V_{\phi}(s) - (r + \gamma V_{\phi}(s')))\nabla_{\phi} V_{\phi}(s) = g
$$

对应的 Python 代码为：

```python
# Single transition; terminal targets do not bootstrap.
pred = V_phi(s0)
with torch.no_grad():
    target = r if terminated else r + gamma * V_phi(s1)
loss = 0.5 * (pred - target).square()
loss.backward()
```

最终，正确的 TD 算法如下：

<Algorithm title="Value function approximation with TD">

**While** not converged:

1. 从固定策略的 rollout 中采样非终止起点 $s_0\sim d^\pi$，再采样 $a_0\sim\pi(\cdot\mid s_0)$ 和 $(r_0,s_1)\sim p(\cdot,\cdot\mid s_0,a_0)$。
2. compute TD target
   $$
   y = \begin{cases}
   r_0 + \gamma \, \mathrm{sg}[V_{\phi}(s_1)], & \text{if } s_1 \neq \langle\text{term}\rangle \\
   r_0,                                         & \text{otherwise}
   \end{cases}
   $$
3. $g = (V_{\phi}(s_0) - y) \nabla_{\phi} V_{\phi}(s_0)$.
4. Update $\phi$ using $g$ with an optimizer.

</Algorithm>

<Note variant="remark" emoji="⚠️">
  上述做法是 **semi-gradient method**：bootstrap target
  依赖当前参数，但更新时不对 target
  求导。因此它一般不是某个固定监督损失的完整梯度。若不使用 stop-gradient，
  得到的是 sampled Bellman-residual loss 的梯度；它对应另一个目标，而且对随机
  transition 的 Bellman residual 构造无偏梯度通常还会遇到 double-sampling 问题。
</Note>

#### k-step TD

实际上，我们可以进一步推广 TD 到多步场景，注意到：

$$
\begin{aligned}
V^{\pi}(s_0) &= \mathbb{E}^{\pi}[r_0 + \gamma V^{\pi}(s_1) \mid s_0] \\
&= \mathbb{E}^{\pi}[r_0 + \gamma \mathbb{E}^{\pi}[r_1 + \gamma V^{\pi}(s_2) \mid s_1] \mid s_0] \\
&= \mathbb{E}^{\pi}[r_0 + \gamma r_1 + \gamma^2 V^{\pi}(s_2) \mid s_0].
\end{aligned}
$$

因此：

$$
V^{\pi}(s_0) = \mathbb{E}^{\pi}[r_0 + \gamma r_1 + \gamma^2 V^{\pi}(s_2) \mid s_0]
$$

重复这个过程 $k$ 次，我们就可以得到 $k$ step TD:

$$
V^{\pi}(s_0) = \mathbb{E}^{\pi}\left[\sum_{i=0}^{k-1} \gamma^i r_i + \gamma^k V^{\pi}(s_k) \mid s_0\right]
$$

基于 k-step transition ，我们可以构建对应的目标函数并应用 stop-gradient：

<Algorithm title="Value function approximation with k-step TD">

**while** not converged:

1. 从固定策略的 rollout 中采样非终止起点 $s_0\sim d^\pi$，set $t=0$。
2. **for** $t = 0, \ldots, k-1$, stopping early if the episode terminates:
   - $a_t \sim \pi(\cdot \mid s_t)$
   - $(r_t, s_{t+1}) \sim p(\cdot, \cdot \mid s_t, a_t)$
3. Let $n\leq k$ be the number of collected transitions and compute
   $$
   y = \begin{cases}
   \sum_{t=0}^{n-1} \gamma^t r_t + \gamma^n \, \mathrm{sg}[V_{\phi}(s_n)], & \text{if } s_n \neq \langle\text{term}\rangle, \\
   \sum_{t=0}^{n-1} \gamma^t r_t, & \text{otherwise}.
   \end{cases}
   $$
4. $g \gets (V_{\phi}(s_0) - y) \nabla_{\phi} V_{\phi}(s_0)$.
5. Update $\phi$ using $g$ with an optimizer.

</Algorithm>

#### Q-Function Evaluation

$Q^\pi(s,a)$ 与 $V^\pi(s)$ 的区别只是额外固定当前动作。后续仍遵循同一个 $\pi$，因此不必重新推导一套训练方法。
将网络输入从 $s_t$ 换成 $(s_t,a_t)$，MC target 仍是 $G_t$；one-step TD target 为

$$
y_t^Q=\begin{cases}
r_t,&s_{t+1}\text{ is terminal},\\
r_t+\gamma\,\mathrm{sg}[Q_\phi(s_{t+1},a_{t+1})],
\quad a_{t+1}\sim\pi(\cdot\mid s_{t+1}),&\text{otherwise}.
\end{cases}
$$

采用相同的 semi-gradient 更新：

$$
\phi\gets\phi-\alpha\bigl(Q_\phi(s_t,a_t)-y_t^Q\bigr)\nabla_\phi Q_\phi(s_t,a_t).
$$

也可以将采样的 $Q_\phi(s_{t+1},a_{t+1})$ 替换为
$\sum_{a'}\pi(a'\mid s_{t+1})Q_\phi(s_{t+1},a')$，对下一动作显式求期望。
前者是 sampled SARSA-style evaluation，后者是 Expected SARSA-style evaluation；这里只借用其 backup 形式，策略仍固定。
k-step target 同样是累计前 $k$ 步奖励，再接上剩余状态动作的 bootstrap value，并在提前终止时去掉 bootstrap。

<Note variant="info">

这里下一动作来自固定 $\pi$，不能随手把它换成 $\arg\max_{a'}Q_\phi(s',a')$。
一旦把“按当前策略取平均”换成“选择价值最大的动作”，我们就在改变 backup 的目标，进入下一章的 control 问题。

</Note>

### MC v.s. TD

MC 必须等待 episode 结束，然后用真实 return 监督每个已访问状态。
对固定状态而言，sample return 是 $V^\pi$ 的无偏估计，但长轨迹中的 variance 可能很高。

TD 使用 $V_\phi(s_{t+1})$ bootstrap，不需要等待完整 episode，通常 variance 更低，但 target 会受到当前 value approximation error 的影响。
这里所谓的 “TD 有偏” 主要是指有限训练阶段的 bootstrap target；在满足收敛条件的 tabular on-policy 场景中，TD 仍然可以收敛到真实的 $V^\pi$.

k-step TD 在两者之间插值：

$$
\text{TD(0)}
\xleftarrow{\quad k=1\quad}
\text{k-step TD}
\xrightarrow{\quad k\geq T-t\quad}
\text{MC}.
$$

配套代码位于 [ToyLLM 项目](https://github.com/MaoSong2022/toyllm)。在仓库根目录运行：

```bash
uv sync
uv run python scripts/run_tutorial_control.py --episodes 10000 --seeds 5 --output outputs/tutorial_control.json
```

脚本显式使用 `failure_reward=0.0, strip_eos=True`，其中代码的 `<BOS>` 对应本文的固定 prompt 初始状态 $x$，`<EOS>` 对应数学记号中的终止 token。
`hand_example` 同时报告 backward evaluation 与 matrix solve 的精确值；两者都应得到初始 value $0.15$。
`evaluation` 部分按 seed 报告 MC/TD 的初始状态估计、初始状态绝对误差和全状态 MAE，整个过程中固定策略的动作概率不变。
TD 使用常数步长 $0.1$，所以有限步结果可能波动，不应要求每个 seed 都精确等于解析值。

现有 `make_bow_feature_extractor` 可用于线性函数逼近实验，但 bag-of-tokens 不保留顺序：例如 prefix `A B` 和 `B A` 会有相同表示。
在更长的 exact-match 任务中，它们可能有不同的真实 value，因此该表示可能无法拟合所有状态。函数逼近提供共享能力，也会引入表示误差。

### Takeaway

- Policy evaluation 始终固定 $\pi$；更新的是 $V^\pi$ 或 $Q^\pi$ 的估计。
- 完整模型允许精确求解，MC/TD 则用 rollout 替代对整个环境的枚举。
- MC 使用完整 return；TD 使用 bootstrap；k-step TD 在等待奖励和依赖估计之间提供选择。
- Function approximation 可以让不同 prefix 共享表示，但不保证自动解决稀疏奖励或状态覆盖问题。
- 当 $\gamma=1$ 且只有 terminal binary reward 时，$V^\pi$ 是当前策略最终成功的概率；有 discount 或其他奖励项时，应解释为相应的期望回报。

回到本章开头，我们现在可以估计出 $V^\pi(x)=0.15$ 和 $Q^\pi(x,B)=0.5$，但策略依旧以 $0.6$ 的概率选择无法成功的首 token $A$。
下一章的问题因此很自然：**既然已经知道动作的好坏，怎样利用这些价值改进策略？**
