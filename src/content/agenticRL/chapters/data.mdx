## Data

Agentic 训练数据由三部分构成：

1. environment: 比如 code repository、web browser 等，让模型理解不同环境
2. tools: 提供信息或改变环境，让模型学会使用不同工具
3. verifier: 比如代码单元测试、proof 的 math checker、DOM scripts 等，定义可完成的目标

关键是 environment 与 verifier 的 diversity。Mach-Mind-4-Flash [@Mach-Mind-4-Flash] 介绍了 EnvScaling，用于提高 multi-turn agentic RL 表现。工具层面的探索会影响模型能力上限；MiMo-V2.6 [@MiMo-V2.6] 发现 scaling harness 也可以迁移到其他 harness。
