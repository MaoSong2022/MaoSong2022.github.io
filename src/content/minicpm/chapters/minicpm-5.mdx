## MiniCPM5-2B

MiniCPM5-2B 的数据包括：

1. UltraX, web pre-training dataset
2. UltraData-Code, coding data
3. UltraData-SFT-agent-2609, 500K agent training examples
4. UltraData-RL-2609, 80K RL training examples

作者主要强调了 post-training 过程中的 RL + OPD 训练策略，RL 作者使用了 JustRL II 算法
