## KAT

KAT-Coder-V1 [@KAT-Coder-V1] 和 KAT-Coder-V2 [@KAT-Coder-V2] 是快手提出的用于 coding 的大模型系列，前者发布于25年10月，后者发布于26年3月。

### KAT-Coder-V1

KAT-Coder-V1 基于 Qwen3 [@Qwen3] 进行 mid-train, SFT, RL 来提高其 coding 能力

SFT 时，作者提到了两个改进：

1. error-masked SFT, 对于 toll call error 的 token, 将其 mask 掉，避免影响模型表现
2. Tree-Structured Trajectory Training, 将 multi-branch trajectories 组织成 subtrees, 保证训练稳定性

agentic RL 训练时，作者提出了 Trie Packing, 来解决 multi-trajectory 的内存占用问题

对于算法， 作者提出了基于难度和 entropy 的 advantage scaling 技巧，最终的 advantage 计算方式为

$$
A_{ij}' = \alpha_i^{group}\beta_{ij}^{sample}
$$

其中

$$
\alpha_i^{group}  = 1 + \lambda(D_i-\bar{D}), \beta_{ij}^{sample} = 1+ \mu(H_{ij}-\hat{H}_i)
$$

分别代表一个 group 里的 task 难度系数和一个 group 里某个 token 的 entropy 系数

### KAT-Coder-V2

KAT-Coder-V2 基于 [KAT-Coder-V1](#kat-coder-v1) continue post-training 得到，训练过程包括 SFT, RL 和 MOPD 三个阶段。

作者首先介绍了 KwaiEnv, 一个用于 agentic coding 的 infra.

post-training 阶段，作者先基于初始模型通过 SFT 和 RL 训练的到 5 个专家，最后通过 MOPD 进行合版。

数据处理：

- SWE-agent: 爬取，验证和执行，收集得到 30k training samples, 作者还构建了 code comprehension 任务来提高模型相应能力
- WebCoding-agent: 构建了 user perception, design rationale, technical implementation 的分阶段 pipeline
- Terminal-agent: 通过专家标注，multi-agent synthesis, SWE-format 数据转换和开源数据集成得到
- WebSearch-agent: 与 Kimi-k3 [@Kimi_K3] 类似使用构建知识图谱然后进行检索
- General-agent: 包含 instruction following, general QA, code-math reasoning 相关 domain

RL 训练时，作者使用了大概 100k samples.

作者使用了 turn-level GSPO [@GSPO] 来进行训练，其 importance ratio 定义为

$$
r_{turn}^{(n)}(\theta) = \prod_{i\in\mathcal{T}_n}\frac{\pi_{\theta}(y_i\mid x, y_{<i})}{\pi_{\theta_{old}}(y_i\mid x, y_{<i})}
$$

其中 $\mathcal{T}_n$ 是一个 turn.
